# 반려동물 테스트 결과 화면 리디자인 — 참고 시안

이 폴더는 **디자인 참고용**이에요. 배포 대상이 아니에요. (deploy.sh 화이트리스트에 넣지 말 것)

## 파일
- `Main.dc.html` — 결과 화면 (390×844, 모바일)
- `Story.dc.html` — 인스타 스토리 공유 카드 (540×960, 9:16)
- `Face.dc.html` — 성향별 얼굴 SVG (cat/dog × lazy·explorer·shy·boss·sweet·grumpy, 12종)
- `Faces.dc.html` — 얼굴 12종 모아보기 + 성향별 포인트 색
- `DogSizes.dc.html` — 강아지 소·중·대형 머리 틀 (소형견 = 작고 축 처진 복슬 귀)

※ `.dc.html`은 디자인 툴 전용 포맷이에요(`{{ }}` 바인딩, `sc-if`, `sc-for`, `dc-import`). 그대로 쓰지 말고 **스타일·SVG·레이아웃만 참고**해서 quiz.html 구조에 맞게 옮기세요.

## 확정된 디자인 방향
- 크림 바탕 `#FBF6EC`, 진한 글씨·테두리 `#1C1B18`
- 성향별 포인트 색: 라임 `#C8F169`, 옐로 `#FFD24A`, 핑크 `#FF8FC5`, 스카이 `#8FD3FF`, 살구 `#FFB38A`, 라벤더 `#C9B8FF`
- 핫핑크 낙서 밑줄 `#FF4FA3`, 연핑크 칩 `#FFD6EA`
- 손그림 느낌: Gaegu 폰트(제목 포인트), 2~2.5px 검은 테두리, 살짝 비대칭 border-radius, 살짝 기울어진(rotate) 해시태그 스티커
- 본문 폰트: Pretendard
- 버튼: 스토리 카드 저장(검정) / 카톡 공유(#FEE500) / 다시 하기(텍스트 링크)

## 작업 규칙
- 결과 이름·설명·궁합 문구는 시안의 예시예요 → **quiz.html의 실제 유형 데이터**를 그대로 사용
- 실제 유형마다 6개 mood 중 가장 가까운 얼굴과 포인트 색을 매칭 (매칭표를 먼저 보여주고 확인받기)
- 테스트 로직·점수 계산·공유 기능은 건드리지 말고 **결과 화면 UI만** 변경
- 배포는 사용자가 "배포해줘"라고 할 때만
