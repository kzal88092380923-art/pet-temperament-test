# 반려동물 테스트 — 통일 규칙 (2026-10-03 확정)

앱이 번잡한 원인: 글꼴 2종(Gaegu + Pretendard)·굵기 5단계, 이모지 226개(104종), 기울어진 요소 21곳, 얼굴은 고양이·강아지만.

## 1. 글꼴 — Pretendard 하나만
- Gaegu(손글씨) 완전 제거 (`--hand` 변수 포함)
- 굵기 3단계만: 제목 800 / 소제목·강조·버튼 700 / 본문 500
- 크기 기준: 제목 28 / 소제목 17 / 본문 15 / 보조 13 (px)

## 2. 이모지 0개
- 질문 보기·칩·버튼·섹션 제목의 이모지는 삭제하고 글자만
- 꼭 필요한 곳(성격 특성 8개, 공유·저장·링크·다시하기·쿠팡 버튼)만 Rules.dc.html의 아이콘 SVG 사용
- 아이콘 스타일: viewBox 32, 검정 #1C1B18 선 2.4, 둥근 끝, 포인트 색 채움 1개

## 3. 얼굴 — 모든 동물 × 모든 성격 (Face.dc.html)
- 머리(동물별 4종: cat, dog, rabbit, hamster=기타) + 표정(성격별 8종) 두 겹을 겹쳐 그림
- 성격 → 표정·색:
  활발한 사랑꾼 sweet #FFB38A / 집사 바라기 lazy #C8F169 / 자유로운 영혼 boss #8FD3FF / 섬세한 감성파 shy #FF8FC5
  장난꾸러기 탐험가 explorer #FFD24A / 모범생 우등생 smart #9FE8C9 / 나만의 법칙 보스 grumpy #C9B8FF / 유니크한 개성파 unique #FF8A7A
- 강아지는 기존 크기별 머리(dogSize 소·중·대)를 유지하고 표정 층만 공용으로
- 동물 선택 카드(강아지·고양이·토끼·기타)도 이모지 대신 이 얼굴(기본 표정 lazy)로
